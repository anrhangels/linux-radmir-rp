# Что исправлено и как это работает

## Новая графика

В исходной проверке игра с новой графикой падала при обработке времени в библиотеке UCRT и при загрузке графических эффектов через D3DX. После установки оригинальных библиотек Microsoft игра запустилась.

Установщик подготавливает **UCRT, D3DX9_43, D3DCompiler_43 и D3DCompiler_47** через Winetricks в выбранном префиксе Radmir. Системные DLL Linux не заменяются. Перед изменениями сохраняются копии соответствующих DLL и файлов реестра префикса.

Пользователю не нужно скачивать отдельные DLL с неизвестных сайтов. Если проверка библиотек не прошла, установщик остановится и покажет журнал.

## Музыкальные адреса с кириллицей

Обычные звуки в исходной проверке работали, а музыкальные MP3 по некоторым адресам с кириллицей не открывались. Библиотека BASS возвращала ошибку `2`. Проверка с той же игровой библиотекой показала: после преобразования адреса в UTF-8 файл открывается. Пользователь подтвердил отсутствие прежней ошибки в игре.

Помощник, запускаемый командой `radmir`:

1. Сохраняет три прежних параметра прокси в реестре префикса Radmir.
2. Запускает локальный HTTP-посредник на `127.0.0.1` и свободном порту.
3. Преобразует путь только для музыкальных HTTP-адресов `music.radmir.online`.
4. Передаёт прочие HTTP GET-запросы без такого преобразования и пропускает HTTPS через туннель, без расшифровки.
5. После выхода возвращает сохранённые параметры и останавливает помощник.

DLL игры не меняются. Системный прокси Linux и другие Wine-префиксы не настраиваются. Пока помощник работает, запросы этого префикса могут проходить через него; поэтому для игры оставляйте процесс запуска работающим.

Обработчик не объявлен универсальным исправлением любых сетевых ошибок. Голос, обычные звуки, доступность сервера и произвольные новые музыкальные сервисы требуют отдельных проверок.

Если процесс прервался и восстановление не выполнилось, план остаётся на диске. Закройте игру и используйте:

```bash
~/.local/bin/radmir --restore
```

## Экран Full HD

При запуске помощник смотрит, подключён ли уже экран **1920×1080**. Если да и он не основной в Xwayland, помощник временно делает его основным. После завершения прежний выбор возвращается.

Он не создаёт фиктивный монитор, не переключает разрешение, масштаб или расположение экранов. Если подходящего экрана нет, используются текущие настройки. Если пользователь сам сменил основной экран во время сеанса, восстановление не должно затирать этот новый выбор.

В системе без доступного Xwayland проверка экрана пропускается. Если остался план восстановления после сбоя, для его применения нужен доступный сеанс Xwayland.

## Отключить исправление для сравнения

На один запуск можно отключить обработку музыкальных адресов:

```bash
~/.local/bin/radmir --no-audio-fix
```

Или временный выбор основного экрана:

```bash
~/.local/bin/radmir --no-display-fix
```

Это параметры команды запуска, а не установщика. Изменения не удаляют библиотеки графики. При отключённой обработке музыкальных адресов прежняя ошибка музыки может вернуться.

Все действия по запуску, сохранению и возврату настроек проходят под одной блокировкой: второй экземпляр этого помощника не должен менять настройки поверх первого.
