# Linux RP Series: оформление

Общая композиция репозиториев: авторский широкий баннер, краткая карточка проекта, пять пронумерованных разделов, карта установки, иллюстрация шрифтов/исправлений и спокойный футер. Инструкции на русском; название игры и цвет акцента меняются под проект.

| Элемент | Значение |
|---|---|
| Фон | `#11101B` |
| Основной текст | `#F5EFEB` |
| Вторичный текст | `#AEA5B9` |
| Radmir | `#B7A5F5` — ночной город |
| Дополнительные цвета | `#FFB076`, `#8FD0C4` |
| Заголовки | Плотный гротеск, крупная композиция |
| Подписи | Моноширинный шрифт, номера маршрутов |
| Графика | Собственная векторная пиксельная городская сцена; без чужих логотипов и игровых скриншотов |

GitHub не позволяет навязать свой CSS всему README. Поэтому выразительные шрифты находятся внутри наших изображений, а инструкции остаются обычным доступным Markdown с поиском и копированием команд.

Исходник иллюстраций: `assets/create_art.py`, результаты — PNG и SVG. Установка игры не требует Cairo. Для редактирования иллюстраций дизайнеру нужны Python и pycairo; запуск из корня: `python3 assets/create_art.py`.

Для Amazing вместо заявления об установке должна быть карточка исследования с честным статусом неудачного запуска. Province пока остаётся заготовкой. Общий стиль не означает одинаковый результат совместимости.
