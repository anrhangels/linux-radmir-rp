# Оформление Linux RP

Новая серия создана с нуля по трём визуальным ориентирам автора: окно терминала с пиксельной типографикой, светлая редакционная карточка с засечками, тёмные карточки веером. Чужие логотипы и названия продуктов не используются.

Общая основа: бумага `#F5F1E9`, чернила `#292824`, терминал `#191918`. Arizona использует терракоту `#D77C60`, Radmir — приглушённый зелёный `#82A492`. У каждого проекта собственный текст и карточки компонентов.

Шрифты: DejaVu Serif для редакционных заголовков, DejaVu Sans для пояснений, DejaVu Sans Mono для служебных подписей. Пиксельные названия рисуются собственной сеткой, без внешнего шрифтового файла. Это иллюстрации документации, а не снимки работающей игры.

Три изображения: обложка, четыре этапа установки, карточки шрифтов или исправлений. Инструкции остаются доступным Markdown. GitHub не поддерживает собственный CSS README.

Исходник — `assets/create_art.py`; результаты — SVG и PNG. Для пересборки нужны Python 3, pycairo и DejaVu. Из корня репозитория: `python3 assets/create_art.py`. Эти зависимости нужны только для редактирования оформления.
