# Что делать при ошибке

## Установка и терминал

**`install.sh: No such file or directory`.** Терминал открыт не в папке проекта. Выполните `ls`: среди файлов должен быть `install.sh`. [Как открыть нужную папку →](installation.md#как-открыть-терминал-в-нужной-папке)

**Не видно пароль при вводе.** Это обычное поведение терминала. Введите пароль пользователя Linux и нажмите Enter. Пароль от игры или GitHub скрипт не запрашивает.

**Нужно закрыть Radmir или Faugus.** Закройте игру и лаунчер, а для установки — также Faugus. Повторите ту же команду. Скрипт не завершает игровую сессию принудительно.

**Параллельная операция или запуск.** Второй процесс не должен менять те же настройки. Дождитесь завершения предыдущего или закройте его штатно. Не удаляйте файл блокировки ради обхода проверки.

## Загрузка

**Прервалось скачивание.** Проверьте сеть и повторите установку. Проверенные готовые файлы в кэше используются повторно; частичные загрузки не запускаются.

**Недоступен сервер официального лаунчера.** Можно скачать EXE с [официального сайта](https://radmir.online/) и выполнить:

```bash
bash install.sh --installer auto
```

Скрипт учитывает системную папку загрузок, `Downloads` и `Загрузки`. Для конкретного файла передайте полный путь через `--installer`. Proton, UMU, Winetricks и его библиотеки тоже требуют сетевого доступа.

**Не совпала сумма или изменился `latest.yml`.** Непроверенный EXE не запускается. Повторите после проверки сети; если ошибка остаётся, приложите точный текст к [сообщению о проблеме](https://github.com/anrhangels/linux-radmir-rp/issues/new/choose). Не отключайте TLS и контрольные суммы для обхода ошибки.

## Лаунчер

**Установщик завершился, но лаунчер не найден.** Посмотрите `launcher-install.log` в напечатанном каталоге. В текущем маршруте ожидается `Program Files (x86)/RADMIR Games/Launcher/RADMIR Launcher.exe` внутри префикса. Если официальный установщик изменил путь, сообщите фактическое расположение; не переименовывайте EXE игры наугад.

**Непонятно, что выбрать в общем лаунчере.** Для этой инструкции выбирайте **RADMIR CRMP**. Другие проекты, включая GTA V, не проверены этими настройками.

**Лаунчер открылся сам во время установки.** Закройте его окно, чтобы скрипт закончил подготовку шрифтов и ярлыка. После сообщения «Готово» открывайте через наш ярлык или `~/.local/bin/radmir`.

## Графика

**Новая графика падает или сообщается о библиотеках.** Выполните:

```bash
~/.local/bin/radmir --check
```

Если не готовы библиотеки, закройте игру и повторите из папки репозитория:

```bash
bash install.sh
```

Проверьте журнал `libraries.log` по напечатанному пути. Не скачивайте случайные DLL вручную. Установщик проверяет UCRT, D3DX9_43 и D3DCompiler_43/47 для двух архитектур.

Успешная проверка файлов не гарантирует успешный запуск графики: при сохранении ошибки нужны игровой журнал, видеодрайвер и шаги воспроизведения.

## Музыка

**Обычные звуки есть, музыкальные файлы не открываются.** Убедитесь, что запускали через наш ярлык или `~/.local/bin/radmir`. Прямой запуск EXE или запись Faugus не включает локальную обработку адресов музыки.

Если использовали `--no-audio-fix`, повторите обычный запуск. При запуске из терминала не закрывайте его до выхода из игры и лаунчера.

Помощник исправляет проверенный случай кодировки адресов `music.radmir.online`, а не любую причину отсутствия звука. Проверьте также громкость, доступность сервера музыки и конкретный адрес. Голосовой чат — отдельная проверка.

**После сбоя остались параметры прокси.** Закройте игру и выполните:

```bash
~/.local/bin/radmir --restore
```

Если восстановление завершилось ошибкой, сохранённый план не удаляется. Не стирайте его до разбора журнала. Системный прокси Linux этот инструмент не изменяет.

## Экран

**Не хотите менять основной экран.** На один запуск:

```bash
~/.local/bin/radmir --no-display-fix
```

**Нет экрана 1920×1080.** Это не ошибка: используются текущие настройки. Фиктивный экран не создаётся.

**После прерывания сохранился другой основной экран Xwayland.** При доступном графическом сеансе используйте `~/.local/bin/radmir --restore`. При ручной смене основного экрана во время игры помощник старается сохранить ваш новый выбор.

## Ярлык и текст

**Нет ярлыка в меню.** После первой установки Flatpak иногда нужен выход из сеанса Linux и повторный вход. До этого используйте `~/.local/bin/radmir`.

**`radmir: command not found`.** Короткая команда зависит от PATH. Полный путь `~/.local/bin/radmir` работает независимо от него, если установка дошла до создания команды.

**Квадраты или вопросы вместо букв.** [Настройка шрифтов →](fonts.md)

## Логи и диагностика

Журналы находятся в `~/.local/state/linux-radmir-rp/logs/`. Точный путь выводится во время установки или запуска. `~` — ваша домашняя папка. Для нестандартного XDG_STATE_HOME путь будет другим.

В [сообщении об ошибке](https://github.com/anrhangels/linux-radmir-rp/issues/new/choose) укажите:

- дистрибутив и версию Linux;
- видеокарту, драйвер и графический сеанс, если знаете;
- команду установки и запуска;
- точный шаг и текст ошибки;
- относящуюся к проблеме часть журнала.

Перед публикацией просмотрите журнал и удалите личные данные, если они там есть. Игровые файлы и пароли прикладывать не нужно.
