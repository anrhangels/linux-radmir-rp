# Короткий словарь

Эти слова встречаются в сообщениях установщика и технической документации. Для обычной установки достаточно следовать [пошаговой инструкции](installation.md).

| Слово | Простое объяснение |
|---|---|
| Репозиторий | Папка проекта на GitHub: скрипты, картинки и инструкции. Здесь нет самих игровых файлов. |
| Архив ZIP | Один файл, в который упакована папка. Перед запуском скрипта архив нужно распаковать. |
| Терминал | Программа для ввода команд. Команда выполняется после нажатия Enter. |
| Скрипт | Файл с последовательностью команд. Здесь `install.sh` запускает подготовку и установку. |
| Дистрибутив | Вариант Linux: например, Ubuntu, Arch или Fedora. |
| Пакетный менеджер | Инструмент вашей системы для установки программ. Скрипт сам выбирает подходящий. |
| `sudo` | Способ выполнить отдельную команду с правами администратора. Весь установщик через него запускать не нужно. |
| Flatpak | Способ устанавливать приложения Linux вместе с нужными им компонентами. |
| Flathub | Каталог приложений Flatpak. Отсюда устанавливается Faugus. |
| Faugus | Приложение для управления запуском Windows-игр на Linux. Установщик создаёт в нём запись Radmir. |
| Wine | Слой совместимости, который позволяет запускать Windows-программы на Linux. Это не сама Windows. |
| Proton / GE-Proton | Набор компонентов на основе Wine, приспособленный для игр. В этом проекте используется GE-Proton. |
| UMU | Компонент, который помогает запускать Proton вне Steam. Установщик подготавливает его сам. |
| Префикс Wine | Отдельная папка с Windows-настройками и диском `C:` для игры. Это не раздел диска и не переустановка Linux. |
| Runner | Выбранная сборка Proton, через которую запускается игра. |
| Runtime | Набор библиотек, нужный программе во время работы. Flatpak/Faugus загружают свои необходимые компоненты. |
| Лаунчер | Официальная программа Radmir, через которую скачивают и запускают игру. |
| Клиент игры | Сама игра и её файлы. Их загружает официальный лаунчер. |
| EXE / `.exe` | Исполняемый файл Windows: например, установщик лаунчера. |
| Библиотека | Вспомогательный компонент, который использует программа. В игровом окружении многие библиотеки уже входят в Proton и runtime. |
| Vulkan | Графическая технология. Для работы игры через выбранное окружение нужен видеодрайвер с её поддержкой. |
| Xwayland | Способ запускать X11-приложения в сеансе Wayland. Полезен при разборе ошибок масштаба и мыши. |
| Fontconfig | Компонент Linux, который помогает программам находить шрифты. |
| CEF | Компонент для отображения интерфейса, похожего на веб-страницу, внутри игры. В таких диалогах проверялись эмодзи. |
| MangoHud / HUD | Необязательная панель поверх игры: FPS, время кадра и другие показатели. |
| FPS | Сколько кадров игра показывает за секунду. |
| Лог / журнал | Текстовый файл с сообщениями программы. Помогает выяснить причину ошибки. |
| Резервная копия | Сохранённый прежний вариант файла, к которому можно вернуться. |
| Откат | Восстановление файлов из резервной копии. Это не обязательно удаление установленных программ. |
| Контрольная сумма | Проверка, что скачанный файл совпадает с опубликованным и не был повреждён. |
| Кэш | Папка для уже скачанных или подготовленных данных. Здесь загрузки скрипта хранятся отдельно от папки загрузок браузера. |
| `$HOME` и `~` | Обозначения вашей домашней папки. Например, `~/Загрузки` — папка «Загрузки» внутри неё. |
| `PATH` | Список папок, в которых терминал ищет команды. Если `radmir` не находится, используйте `~/.local/bin/radmir`. |
| XDG | Стандарт расположения пользовательских папок и настроек Linux. Обычно менять эти параметры не требуется. |
| Git | Инструмент для скачивания исходников и отслеживания изменений. Для установки из ZIP он не нужен. |
| Issue | Сообщение о проблеме на GitHub. В нём описывают ошибку и шаги её появления. |

`/путь/к/папке` и `ДАТА` в технических примерах — места для ваших значений. Их нельзя просто скопировать и ожидать, что такая папка уже существует. Полные команды обычной установки приведены без таких замен в [инструкции для новичков](installation.md).

**Прокси в этом проекте** — локальный помощник между приложением и сервером. Он нужен для музыкальных адресов, а не для обхода блокировок. **Кодировка** — способ записать буквы в байтах; несовпадение кодировок может мешать открытию адресов с кириллицей. **DLL** — библиотека Windows; нужные для графики библиотеки устанавливаются в префикс игры.
