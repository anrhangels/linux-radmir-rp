# Шрифты, кириллица и эмодзи

## Обычная установка

Скрипт автоматически добавляет **DejaVu Sans** для основного текста и **Noto Color Emoji** для эмодзи, копирует их в выбранный префикс и пользовательскую папку шрифтов Linux.

Для обычного запуска заранее искать Microsoft-шрифты не нужно. При этом отдельный полный игровой тест всех букв и эмодзи именно в Radmir после нового установщика пока не проведён. Подтверждённые исправления этого проекта относятся прежде всего к новой графике и музыкальным адресам.

Если текст отображается правильно, дополнительных действий не требуется.

## Если остаются квадраты или вопросы

Закройте игру и лаунчер, затем откройте их повторно через наш ярлык. Проверьте тот же диалог. Если проблема сохраняется, можно подключить оригинальные Segoe из своей Windows.

| Файл | Семейство |
|---|---|
| `segoeui.ttf` | Segoe UI |
| `seguisb.ttf` | Segoe UI Semibold |
| `seguiemj.ttf` или `SegoeUIEmoji.ttf` | Segoe UI Emoji |

Из папки репозитория, при закрытых игре и Faugus:

```bash
bash install.sh --fonts-only --prefix "$HOME/Games/radmir-crmp/prefix" \
  --windows-fonts "/путь/к/Windows/Fonts"
```

Замените последнюю папку реальным путём. Если использовали другой префикс, укажите его. Названия файлов распознаются без учёта регистра. Оригинальные Microsoft-шрифты в репозитории не распространяются.

## Для опытных пользователей

Файлы регистрируются в реестре выбранного префикса. Для отсутствующих Segoe могут создаваться Wine-подстановки на свободные семейства; при импорте оригинального семейства ранее созданная нами соответствующая подстановка снимается. Неизвестные пользовательские подстановки не удаляются автоматически.

Перед изменениями сохраняются файлы реестра и изменяемые шрифты. [Возврат по снимку →](advanced.md#восстановление-файлов)

Проблема музыкальных URL с кириллицей не исправляется установкой шрифта: это отдельная обработка кодировки адреса. [Как работает помощник музыки →](fixes.md#музыкальные-адреса-с-кириллицей)
