# Установка по шагам

Эта инструкция для **RADMIR CRMP на GTA San Andreas**, а не для всех игр общего лаунчера. Знать Wine и Proton для обычной установки не требуется.

## Перед началом

Подготовьте интернет, место для игры и драйвер видеокарты с поддержкой Vulkan. Нужен обычный 64-битный ПК или ноутбук с Linux. [Какие системы предусмотрены →](distributions.md)

Полностью закройте Radmir, его лаунчер и Faugus. Установщик не закрывает игру автоматически: он попросит сделать это перед настройкой файлов.

## 1. Получите папку проекта: Git или ZIP

Выберите один из двух способов. Оба скачивают одни и те же файлы, после чего запускается один установщик.

### Способ 1. Скачать через Git

Откройте терминал из меню приложений. Git скачивает проект с GitHub; он не устанавливает саму игру. Если Git ещё не установлен, выполните шаги ниже.

<a id="установка-git"></a>

### Если Git ещё не установлен

Git — программа, которая скачает папку этого проекта с GitHub. Она нужна только для первого способа. Откройте **Терминал** из меню приложений и выполните:

```bash
git --version
```

Если появилась строка с версией, переходите к скачиванию проекта. Если написано «команда не найдена», выберите **одну** команду для своей системы:

| Ваша система | Команда установки Git |
| --- | --- |
| Ubuntu, Linux Mint, Debian | `sudo apt update && sudo apt install git` |
| Arch, CachyOS, Manjaro | `sudo pacman -S git` |
| Fedora | `sudo dnf install git` |
| openSUSE Tumbleweed | `sudo zypper install git` |

Не знаете название системы? Откройте «Настройки → О системе». Для SteamOS, Silverblue/Kinoite, NixOS и других особых систем сначала прочитайте [страницу дистрибутивов](distributions.md).

`sudo` разрешает установить системную программу. Введите пароль своего пользователя и нажмите Enter; символы пароля могут не отображаться. Если установка Git закончилась ошибкой, сначала разберитесь с ней или используйте способ с ZIP.

### Скачивание проекта

Вставьте весь блок и нажмите Enter:

```bash
git clone https://github.com/anrhangels/linux-radmir-rp.git "$HOME/linux-radmir-rp" &&
cd "$HOME/linux-radmir-rp"
```

Проект появится в домашней папке под именем `linux-radmir-rp`. Терминал перейдёт в неё только после успешного скачивания. Дальше переходите к разделу **«2. Запустите установку»** на этой странице.

<a id="папка-уже-существует"></a>

### Если папка уже существует

Git не скачивает проект поверх существующей папки. Откройте домашнюю папку в файловом менеджере и найдите `linux-radmir-rp`. Если это ранее скачанный проект и в нём есть `install.sh`, откройте терминал внутри и продолжите установку. Если это другая папка или вы не уверены, скачайте ZIP и распакуйте его в отдельное место. Удалять существующие файлы не требуется.

### Способ 2. Скачать ZIP вручную

Откройте [ссылку на ZIP-архив](https://github.com/anrhangels/linux-radmir-rp/archive/refs/heads/main.zip) или нажмите **Code → Download ZIP** на странице репозитория.

Распакуйте архив через файловый менеджер. Откройте полученную папку `linux-radmir-rp-main`: в ней должны лежать `install.sh`, `README.md` и папки `scripts`, `docs`, `assets`. Сам архив запускать не нужно. Теперь откройте терминал в этой папке по инструкции ниже.

## Как открыть терминал в нужной папке

Откройте папку, нажмите правой кнопкой на свободное место и выберите **«Открыть в терминале»**.

Если такого пункта нет, откройте терминал из меню приложений и перейдите в распакованную папку командой `cd`. Например:

```bash
cd "$HOME/Загрузки/linux-radmir-rp-main"
```

Или, если папка загрузок называется по-английски:

```bash
cd "$HOME/Downloads/linux-radmir-rp-main"
```

Используйте путь к своей папке: после распаковки её имя может отличаться. Кавычки сохраняйте, особенно при пробелах в пути.

Проверьте содержимое:

```bash
ls
```

**Ожидаемый результат:** среди файлов виден `install.sh`.

## 2. Запустите установку

```bash
bash install.sh
```

Не добавляйте `sudo` перед этой командой: нужные права скрипт запросит сам. Он покажет план действий. Для согласия введите `y` и нажмите Enter.

Если система попросит пароль, введите пароль своего пользователя Linux и нажмите Enter. Во время ввода символы могут совсем не отображаться — это нормально.

Для предварительного просмотра без изменений:

```bash
bash install.sh --plan
```

Эта команда только показывает план. Саму установку запускает команда без `--plan`.

## 3. Дождитесь завершения

Скрипт установит нужные программы, подготовит Proton и UMU, скачает официальный лаунчер и установит библиотеки для графики. Затем настроит шрифты, ярлык и панель FPS.

Скачивания могут занимать время. Не закрывайте терминал, пока идёт работа. Если после установки открылся лаунчер Radmir, закройте его окно, чтобы скрипт продолжил настройку.

**Ожидаемый результат:** сообщение «Готово» и команда запуска. Если вместо этого появилась ошибка, используйте [поиск по симптомам](troubleshooting.md).

## Первый вход

Найдите **Radmir CRMP** в меню приложений или выполните:

```bash
~/.local/bin/radmir
```

В официальном лаунчере:

1. Выберите **RADMIR CRMP**.
2. Дождитесь загрузки игровых файлов.
3. Введите свой игровой никнейм.
4. Выберите нужные параметры, при желании — новую графику.
5. Запустите игру и проверьте подключение.

Открытый лаунчер — ещё не подтверждение игрового входа. Проверьте запуск самой игры, графику, звук и повторное открытие после закрытия.

## Повторный запуск

Используйте ярлык или `~/.local/bin/radmir`. Если короткая команда `radmir` работает в вашем терминале, можно использовать её.

Перед каждой игрой установщик повторно запускать не нужно. При запуске из терминала оставляйте его открытым до закрытия игры и лаунчера: помощник музыки работает в этом процессе. Ярлык меню держит помощник без отдельного терминального окна.

Для проверенных исправлений используйте именно эту команду или наш ярлык. Прямой запуск EXE или запись в Faugus сами по себе не включают помощник музыкальных адресов и временную настройку экрана.

## Если официальный EXE уже скачан

Обычно скрипт скачивает его сам. Для локального установщика с [официального сайта](https://radmir.online/) можно выполнить:

```bash
bash install.sh --installer auto
```

Скрипт ищет наиболее свежий EXE с `radmir`, `rdmr` или `hassle` в имени. Учитываются системная папка загрузок, `Downloads` и `Загрузки`.

Если файлов несколько и нужен конкретный:

```bash
bash install.sh --installer "$HOME/Загрузки/RADMIRLauncherSetup.exe"
```

Замените путь и имя своими. Для явно выбранного локального файла опубликованная сумма автоматически не сверяется; в обычной автоматической загрузке сумма проверяется.

## Если запуск прервался

Закройте игру и лаунчер, затем выполните:

```bash
~/.local/bin/radmir --restore
```

Это возвращает сохранённые сетевые настройки префикса и, если требуется, прежний выбор основного экрана Xwayland. Игра не запускается. При следующем обычном запуске скрипт также сначала проверяет сохранённые планы возврата.

Это не восстановление всех файлов установки. Для такого возврата есть отдельная [инструкция по резервным копиям](advanced.md#восстановление-файлов).
