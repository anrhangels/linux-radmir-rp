# Подходит ли моя система

Дистрибутив — это вариант Linux: например, Ubuntu, Arch или Fedora. Скрипт сам определяет семейство вашей системы и выбирает способ установки необходимых программ.

## Обычные настольные системы

| Ваша система | Что предусмотрено |
|---|---|
| Arch, CachyOS, Manjaro, EndeavourOS | Автоматическая подготовка через `pacman`; Radmir CRMP проверялся на Arch |
| Debian, Ubuntu, Linux Mint, Pop!_OS | Автоматическая подготовка через `apt-get`; игровой запуск на этих системах пока не подтверждён |
| Fedora Workstation | Автоматическая подготовка через `dnf`; игровой запуск пока не подтверждён |
| openSUSE Tumbleweed | Автоматическая подготовка через `zypper`; игровой запуск пока не подтверждён |

Для этих систем начните с обычной команды:

```bash
bash install.sh
```

Наличие вашей системы в таблице означает, что для неё подготовлены команды установки зависимостей. Это не означает, что игру уже проверили на каждой из них.

## Видеокарта и драйвер

Драйвер видеокарты должен быть установлен заранее и поддерживать Vulkan. Способ его установки зависит от вашей системы и от NVIDIA, AMD или Intel. Установщик игры не заменяет драйвер автоматически.

Если не уверены в драйвере, используйте справку вашего дистрибутива или укажите систему и видеокарту в сообщении о проблеме. После установки инструментов можно проверить Vulkan командой:

```bash
vulkaninfo --summary
```

Ошибка этой команды — повод разобраться с графическим окружением до игрового теста. Успешный вывод показывает работу Vulkan на хосте, но не гарантирует запуск игры внутри Flatpak.

Для NVIDIA после обновления драйвера обновите компоненты Flatpak командой `flatpak update`; перезагрузитесь, если этого требует обновление драйвера.

## SteamOS, Silverblue, Kinoite, NixOS и похожие системы

У этих систем особые правила установки программ. Скрипт не пытается применять к SteamOS, NixOS или обнаруженной OSTree-системе обычную установку системных пакетов.

Сначала подготовьте необходимые компоненты средствами вашей ОС. После этого можно выполнить:

```bash
bash install.sh --no-system-packages
```

Этот параметр **пропускает**, а не заменяет установку зависимостей. Если чего-то не хватает, пользовательская часть остановится с сообщением. Успешный игровой запуск на этих системах нами не подтверждён.

## Для опытных пользователей: состав зависимостей

| Семейство | Системные пакеты |
|---|---|
| Arch и производные | `python flatpak fontconfig ttf-dejavu xorg-xrandr vulkan-tools ca-certificates` |
| Debian и производные | `python3 flatpak fontconfig fonts-dejavu-core x11-xserver-utils vulkan-tools ca-certificates` |
| Fedora Workstation | `python3 flatpak fontconfig dejavu-sans-fonts xrandr vulkan-tools ca-certificates` |
| openSUSE Tumbleweed | `python3 flatpak fontconfig dejavu-fonts xrandr vulkan-tools ca-certificates` |

Профиль определяется по `ID` и `ID_LIKE` из `/etc/os-release`. Неизвестный дистрибутив не получает случайно выбранную команду установки. Нужны Python 3.10+ с `tarfile.data_filter`, Flatpak, Fontconfig, DejaVu Sans и работающее графическое окружение.

`tarfile.data_filter` есть в Python 3.12+ и актуальных исправленных сборках 3.10/3.11. При его отсутствии обновите Python: небезопасного обхода распаковки нет.

Игровая часть использует общий маршрут Flatpak → Faugus → UMU → Proton. Отдельные DEB/RPM с игрой не требуются. Runtime и расширения устанавливаются средствами Flatpak.

Noto Color Emoji загружается отдельно из закреплённого официального исходника. Это позволяет использовать один формат цветного шрифта: некоторые пакеты дистрибутивов, например Fedora, поставляют другой формат. Размер и содержимое файла проверяются.

Оригинальные Segoe импортируются только из выбранной пользователем папки. Подробнее о шрифтах — в [отдельной инструкции](fonts.md). Старые неподдерживаемые выпуски Linux и ARM в эту поставку не входят.

`xrandr` используется только для временного выбора уже существующего основного экрана в Xwayland. Саму игру и её разрешение этот инструмент не заменяет. На хосте и внутри Flatpak графические компоненты проверяются отдельно; старой 32-битной игре нужны соответствующие компоненты runtime.
